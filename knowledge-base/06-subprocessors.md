# Sub-processors

Vantrel uses the following third-party sub-processors to deliver Vantrel Plan. Customers are notified at least 30 days before any change to this list.

## Infrastructure sub-processors

| Sub-processor | Purpose | Data location |
|---|---|---|
| Amazon Web Services EMEA SARL | Cloud hosting, storage, backups | Region selected by the customer (EU or US) |
| Cloudflare, Inc. | CDN, Web Application Firewall, DDoS protection | Global edge network (traffic in transit only) |
| Datadog, Inc. | Infrastructure and application monitoring, logs | EU (for EU tenants), US (for US tenants) |

## Service sub-processors

| Sub-processor | Purpose | Data location |
|---|---|---|
| Stripe Payments Europe, Ltd. | Billing and subscription payments | EU / US |
| Zendesk, Inc. | Customer support ticketing | EU |
| SendGrid (Twilio Inc.) | Transactional emails (notifications, password resets) | US |
| Microsoft Ireland Operations Ltd. (Azure OpenAI Service) | AI features (Vantrel Assist) | EU Data Zone |

## Notes

- SendGrid only processes user email addresses and the content of transactional notifications. It does not process data from customer models.
- Microsoft Azure OpenAI Service is only used when the customer has enabled Vantrel Assist (see the AI Features Policy).
