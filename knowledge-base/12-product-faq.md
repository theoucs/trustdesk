# Product FAQ

## Which browsers are supported?

Vantrel Plan supports the latest two versions of Google Chrome, Microsoft Edge, Mozilla Firefox and Safari. Internet Explorer is not supported. There is no desktop application to install.

## Is there a mobile app?

There is no native mobile app. Boards and reports can be viewed on tablets through the web browser, but model editing requires a desktop or laptop screen.

## Does Vantrel Plan have an API?

Yes. Vantrel Plan provides a REST API, available on Business and Enterprise plans, to import and export data, manage users and read audit logs. API authentication uses OAuth 2.0 client credentials, and API keys can be scoped to read-only or read-write access. The API is rate-limited to 100 requests per minute per workspace.

## Which integrations are available?

Native connectors are available for Salesforce, HubSpot, NetSuite, SAP S/4HANA, Workday, Snowflake, BigQuery and Microsoft Excel. Files can also be imported in CSV and XLSX format.

## Which languages is the interface available in?

The user interface is available in English, French, German and Spanish.

## Is there a limit on the number of users or models?

Starter includes up to 10 users. Business and Enterprise plans have no hard limit on users. The number of models is unlimited on all plans, within fair-use limits on storage (100 GB per workspace on Business, custom on Enterprise).

## Is there a free trial?

Vantrel offers a guided 30-day trial for qualified prospects, on a sandbox workspace hosted in the EU region.

## Is Vantrel Plan accessible to users with disabilities?

Vantrel is working toward conformance with WCAG 2.1 level AA. An accessibility conformance report (VPAT) is not yet available.
